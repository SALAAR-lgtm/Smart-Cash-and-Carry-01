## 4. PostgreSQL schema status

`database/init.sql` contains the requested empty tables, types, defaults, and foreign-key relationships. The tables are quoted in SQL so their names remain exactly `Category`, `Product`, `Order`, `OrderItem`, and `Admin` in PostgreSQL.

| Table | Implemented columns | Constraints and relationships |
| --- | --- | --- |
| `Category` | `id INTEGER GENERATED BY DEFAULT AS IDENTITY`, `name TEXT` | `id` is the primary key; `name` is required. |
| `Product` | `id`, `name TEXT`, `price NUMERIC(12,2)`, `category_id INTEGER`, `image_url TEXT`, `available BOOLEAN` | `id` primary key; `category_id` references `Category(id)`; `available` defaults to `TRUE`. |
| `Order` | `id`, `customer_name TEXT`, `phone TEXT`, `address TEXT`, `total NUMERIC(12,2)`, `completed BOOLEAN`, `created_at TIMESTAMP` | `id` primary key; `completed` defaults to `FALSE`; `created_at` defaults to `CURRENT_TIMESTAMP`. |
| `OrderItem` | `id`, `order_id INTEGER`, `product_id INTEGER`, `product_name_snapshot TEXT`, `price_snapshot NUMERIC(12,2)`, `qty INTEGER`, `subtotal NUMERIC(12,2)` | `id` primary key; `order_id` references `Order(id)`; `product_id` references `Product(id)`. |
| `Admin` | `id`, `username TEXT`, `password_hash TEXT` | `id` primary key; `username` is required and unique; `password_hash` is required. |

No seed records are present in `init.sql`.

**Important distinction:** the SQL file exists, but no PostgreSQL instance has been started in this environment. Therefore I cannot honestly claim that a live database has been created or that the five tables have been applied and inspected in a running PostgreSQL server.
